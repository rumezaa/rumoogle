Peony is a website cloning service that uses AI to generate near pixel-perfect replicas of any site. Paste in a URL and it scrapes the page with Playwright via Browserbase, runs the design through Anthropic's API for analysis, and returns clean HTML with styles preserved. Supports single-page and multi-page cloning with real-time progress streaming. Built with FastAPI on the backend and Next.js on the frontend.
