Using Python Kivy, I developed an Android mobile application, Blu3Whale ED, designed to support individuals with eating disorders. The app integrates the MealDB API to provide an in-app recipe search engine tailored to user input and leverages Firebase for user authentication and a public chat forum. I implemented Python’s NLTK library to create a Naïve Bayes algorithm that classifies user moods (e.g., happy, sad) based on text inputs found in the library's lexicon dictionary and visualized this data using matplotlib, enabling users to track their emotional well-being in their recovery. The app achieved recognition as a Top 8 Semifinalist in Canada for the Technovation Girls Competition.
